# 骑砍2开服助手

用于 Windows 上《骑马与砍杀2》Bannerlord Co-op MOD 专用服务器的中文开服助手。当前版本为 **v1.6.9**，源码整理日期为 **2026-10-14**。

[打开独立下载页](https://qikan2-launcher-sudazz777.meisen111.chatgpt.site) · [⬇ 下载 Windows 64 位成品 v1.6.9](https://github.com/sudazz777/QiKanKaiFuZhuShou/releases/download/v1.6.9/BannerlordCoopLauncher-v1.6.9-win-x64.zip)

下载后“全部解压”，双击“骑砍2开服助手.exe”。

本项目提供开服与存档管理界面，使用本机已经安装的游戏、MOD 和专用服务器组件。Bannerlord Co-op 是联机 MOD 本体；Bannerlord Coop 简体中文补丁是汉化补丁。

## 功能

- 自动检测 Steam、多盘游戏库、游戏和专用服务器位置，支持首次适配与手动选择安装目录。
- 启动服务器、保存并重启、保存并停止，以及打开游戏。
- 无窗口启动服务器，输出与命令在助手的内嵌控制台处理。关闭助手时先保存并停止服务器，确认退出后关闭窗口。
- 公开 Steam 大厅状态显示。
- 新建或导入战役、立刻保存当前进度、完整导出到桌面。
- 存档改名时同步世界、联机角色记录和两组历史备份。
- 从服务器目录删除存档。
- 设置、修改或取消房间密码，以及自动保存间隔。
- 总难度“冒险家、勇士、霸主”，独立难度和生育死亡等选项。
- 保存设置前备份，保留已有存档与其他配置字段。

## 运行条件

64 位 Windows 与 .NET Framework 4.x。使用服务器功能还需要本机安装 Steam、游戏及匹配版本的 Bannerlord Co-op，专用服务器的 `DedicatedServer` 文件夹必须完整。

当前实现适配并验证过 Coop 0.1.6 / 游戏 1.4.8 的安装与配置格式。其他版本会接受安装检查；新增或改变的必需字段可能需要继续适配。

助手不附带游戏、MOD、服务器、Steam SDK DLL 或用户存档。Steam 联机依赖 Steam 在线、版本匹配及可用网络；公开大厅可见与玩家实际进入战役是两个独立状态。


## v1.6.9 Win11 无窗口启动

服务器以无窗口方式启动，助手通过输入/输出管道显示日志和交互提示、发送命令。启动过程不创建可见控制台窗口，从而避免创建 Windows 11 的终端宿主窗口。关闭助手仍先保存并停止服务器。升级时请先关闭旧助手并等待停服，再启动新版，以使新启动方式生效。

## 已包含的传统控制台兼容处理

助手主窗口保留自己的任务栏图标。连接外部已经运行的传统控制台服务器时，保留其窗口隐藏和任务栏样式处理；新版自行启动的服务器没有独立控制台。

## 已包含的 v1.6.7 默认开服与存档页

打开助手首先显示“开服与存档”。自动或手动启动服务器后保持当前页面；日志仍在“服务器控制台”中查看。安装未完成时，在顶部提示中引导用户到“本机安装设置”完成适配。

## 已包含的 v1.6.6 关闭同步停服

点击关闭后取消待执行的自动重启，等待当前保存/导出完成，通过原控制台发送停服命令，确认服务器退出并释放端口后关闭助手。

## 已包含的 v1.6.5 内嵌控制台

打开助手默认显示“开服与存档”，启动服务器也不会自动切换页面。需要日志时手动切换到“服务器控制台”。日志与协议提示在助手中显示，命令可在下方输入并发送。取消“自动刷新”可暂停画面更新；新版启动的服务器采用后台无窗口模式，命令直接在助手内发送。连接外部已运行的传统服务器时，可按需显示独立窗口。关闭助手时会等待当前保存或导出完成，再保存并停止服务器；确认退出后自动关闭。停服超时会保持助手打开，不强制结束进程。

## 已包含的 v1.6.4 修复

旧版助手在启动前写入客户端 `coop_options.json` 的 `lastServerAddress`。新电脑没有这个可选字段时会出现“配置字段缺失或重复”错误。当前版本取消这项客户端历史地址写入，服务器设置仍严格验证。

本机直连在游戏内填写 `127.0.0.1`，端口 `4200`。房间有密码时填写实际密码，没有密码则留空。好友资料页加入需要助手保持运行及 Steam 加入入口就绪；关闭助手时会保存并停止服务器。
