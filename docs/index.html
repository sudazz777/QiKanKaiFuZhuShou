迁移到新电脑后，重新识别本机安装位置即可。

运行前需要准备什么？

64 位 Windows 与 .NET Framework 4.8。开服还需安装并登录 Steam，准备游戏、匹配版本的 Bannerlord Co-op，以及完整 DedicatedServer 文件夹。

已适配 Coop 0.1.6 / 游戏 1.4.8。助手不附带游戏、MOD 或服务器本体。

本机如何直连？

在游戏的 Direct（直连）中填写地址 127.0.0.1，端口 4200。按服务器实际设置填写密码，没有密码则留空。

好友加入需要什么？

双方游戏与 MOD 版本匹配、Steam 在线且网络可用。好友资料页加入需助手保持运行及加入入口就绪；大厅可见与实际加入战役需要分别验证。

  1. 1

    下载并全部解压

    下载 Windows ZIP 包，右键选择“全部解压”，再打开“骑砍2开服助手.exe”。

  2. 2

    检查本机安装

    让助手自动识别游戏与服务器。没有找到时，在“本机安装设置”中手动选择目录。

  3. 3

    选好战役，启动服务器

    新建或导入战役，调整房间密码与难度，点击“启动服务器”。
