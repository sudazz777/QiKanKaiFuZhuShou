骑砍2开服助手 · v1.6.5 内嵌控制台版（2026-10-14）

先右键压缩包选择“全部解压”，再双击解压后的“骑砍2开服助手.exe”。
只需把“骑砍2开服助手.exe”复制到新电脑，不必复制旧电脑的路径配置或脚本。
程序适用于 64 位 Windows，使用 .NET Framework 4.x。

服务器控制台
启动服务器后，默认不再显示独立黑色窗口，助手会切换到“服务器控制台”页。
页面显示最近 120 行实时输出，包括加载日志和需要输入的交互提示。
如出现 EULA / LICENSE 等提示，请先阅读内容，再按提示在下方输入并点击“发送命令”，或按回车。助手不会替你自动同意协议。
取消“自动刷新”可暂停画面更新；需要完整控制台时勾选“显示独立窗口”。
日常保存、重启与停服仍建议使用主窗口的对应按钮，它们会核对存档状态。
关闭助手后，服务器继续运行，独立控制台会恢复显示。

已包含的新电脑兼容修复（v1.6.4）
旧版提示“配置字段缺失或重复：lastServerAddress”时，是助手错误检查了游戏客户端的上次直连地址。
v1.6.4 已取消这项无关检查，不读取或改写 coop_options.json。首次运行尚无直连记录也可正常保存开服设置。
请关闭旧助手，将本压缩包“全部解压”到独立文件夹，打开其中的 EXE；窗口标题应显示 v1.6.5。
本机在游戏中选择 Direct（直连），手动填写 127.0.0.1、端口 4200；按服务器实际密码填写，未设置时留空。
此修复通过独立模拟目录验证；没有在你截图中的新电脑上实测，也不代表 Steam 网络连接已验证成功。

首次开启
1. 自动查找 Steam、Steam 的多个游戏库、骑砍2游戏目录以及 Coop 专用服务器。
2. 安装完整且版本匹配时，自动创建当前用户的缺失配置和初始世界模板，并保存本机路径。
3. 在“开服与存档”页新建或导入战役，再点“启动服务器”。已有存档、密码和难度会保留。
4. 完成本机适配后，以后开启助手会按已保存的战役设置开服；未选档时不会自动生成新世界。

难度设置
在“详细难度”页选择“冒险家、勇士、霸主”，或逐项调整为“自定义”。
普通项目为“非常简单、简单、写实”；战斗AI与潜行伪装为“普通、资深、挑战”。
两项英雄战死设置使用游戏中的专用选项名称。
“启用生育与死亡”“自动分配家族成员特长”独立于预设，切换总难度时会保留。
关闭生育与死亡时，英雄战死选项不可编辑，已选值保留；预设只调整当前可用项。
霸主预设的潜行与伪装为“资深”，可手动改为“挑战”。
更改后点“保存并重启”生效；未开服时点“启动服务器”。

找不到安装或后来移动了游戏
打开“本机安装设置”，点“重新自动检测”。
也可分别选择 Steam.exe、游戏文件夹和 BannerlordCoopServer.exe，点“检查安装”，再点“保存并完成适配”。
游戏文件夹应包含 bin 和 Modules；服务器需要完整 DedicatedServer 文件夹，包含 engine 和 server-data，不能只放一个服务器 EXE。
检测不到或文件缺失时仍能打开助手设置页；它会列出需要修复的文件。
更改安装位置前请保存并停止服务器。同一安装位置的已运行服务器可直接连接，不会重新初始化其存档。

存档与配置
使用 Windows 当前用户的“文档”位置，支持 OneDrive 文档重定向和中文用户名：
文档\Mount and Blade II Bannerlord\CoopData\DedicatedServer\Game Saves
玩法与难度：文档\Mount and Blade II Bannerlord\CoopData\mod-config.json
安装位置配置保存于当前用户的 LocalAppData\BannerlordCoopLauncher\installation.json。
本机设置不随助手 EXE 迁移；跨电脑或旧路径失效时重新识别。
复制战役时请保留同名 .sav 与 .json，助手也支持完整导出到桌面。

新电脑开服前
新电脑需要安装 Steam、《骑马与砍杀2》及配套 Bannerlord Co-op 联机 MOD，并在游戏启动器启用 Coop。
游戏与服务器版本要匹配，好友要使用对应的游戏与 Coop 构建；请关闭不兼容的其他 MOD。
首次启动服务器时，如显示 EULA / LICENSE 提示，请由使用者阅读并按服务器提示确认。
Steam 联机仍需 Steam 在线以及可用的网络线路。路径适配不会自动修复 Steam 登录或好友网络连接。
本版本已经通过本机只读检测、多 Steam 库、新电脑空配置、重复适配保留数据和版本不匹配的隔离测试；未在另一台实际电脑上验证。

保存与管理战役
“立刻保存”：立即保存当前正在运行的战役，不停止服务器；等底部提示“已保存”后完成。即使下拉框选中了别的存档，也保存当前运行战役。服务器首次加载或正在保存时按钮暂时不可点。
“修改存档名”：选中服务器存档并输入新名称。世界 .sav、同名联机角色 .json 和两组历史备份会一起改名，保留进度且不会覆盖同名战役。当前使用的战役须先“保存并停止”，改名后再开服。
“删除服务器存档”：世界、联机角色记录和同名历史备份会从本机服务器存档目录移走，整组移入 Windows 回收站。当前使用的战役须先保存并停止；删除前请核对名称。
恢复误删时，在回收站还原整个存档文件夹，按其中“恢复说明.txt”把 .sav、同名 .json 和历史备份复制回服务器的 Game Saves 文件夹。不要只恢复世界文件。
列表只显示服务器存档。单机战役请点“导入存档”；删除服务器副本不会删除单机目录中另存的原档。
新档尚未生成时，改名或删除只修改待创建选项，开服后才生成新世界。
“保存设置”保存房间及难度设置；“立刻保存”保存游戏进度。

Bannerlord Co-op 是联机 MOD 本体；Bannerlord Coop 简体中文补丁是汉化补丁。
助手不更改 VK 或其他加速器。Steam 大厅创建与实际进入战役须分别验证，公开大厅不代表香港云服务器。
