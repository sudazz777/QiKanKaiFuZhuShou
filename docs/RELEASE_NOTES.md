# 骑砍2开服助手 v1.6.4

[⬇ 下载 Windows 64 位成品](https://github.com/sudazz777/QiKanKaiFuZhuShou/releases/download/v1.6.4/BannerlordCoopLauncher-v1.6.4-win-x64.zip)

下载 ZIP 后选择“全部解压”，双击“骑砍2开服助手.exe”。成品包仅包含程序和使用说明。

修复新电脑因 `lastServerAddress` 缺失或重复而无法开服的问题，保留服务器配置检查与备份。支持安装检测、服务器启停、存档管理、房间密码及难度设置。

运行条件：64 位 Windows 与 .NET Framework 4.8；开服还需 Steam、游戏、Bannerlord Co-op 和完整 DedicatedServer。已适配 Coop 0.1.6 / 游戏 1.4.8。

发布流程在 Windows 上校验源文件、编译并运行内置自检，通过后打包。真实服务器及好友 Steam 加入需在实际环境中验证。
