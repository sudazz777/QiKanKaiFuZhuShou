# 骑砍2开服助手 v1.6.9

[⬇ 下载 Windows 64 位成品](https://github.com/sudazz777/QiKanKaiFuZhuShou/releases/download/v1.6.9/BannerlordCoopLauncher-v1.6.9-win-x64.zip)

先关闭旧助手并等待停服，再解压新版，双击“骑砍2开服助手.exe”。成品包仅包含程序和使用说明。

服务器改为无窗口启动，不创建可见控制台窗口，以避免 Windows 11 创建终端宿主任务栏入口。助手通过管道显示标准输出、错误输出和无换行交互提示，并发送保存、停服等命令。

保留默认“开服与存档”页及关闭助手时保存并停止服务器的功能。外部已运行服务器保留传统控制台连接方式；新版自行启动的服务器没有独立窗口。

运行条件：64 位 Windows 与 .NET Framework 4.8；开服还需 Steam、游戏、Bannerlord Co-op 和完整 DedicatedServer。已适配 Coop 0.1.6 / 游戏 1.4.8。

发布前在 Windows 上校验源文件、编译并运行内置检查。无窗口流程使用独立模拟服务器验证；真实 Win11 MOD 环境仍需本机复测。
