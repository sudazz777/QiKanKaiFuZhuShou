# 骑砍2开服助手 v1.6.8

[⬇ 下载 Windows 64 位成品](https://github.com/sudazz777/QiKanKaiFuZhuShou/releases/download/v1.6.8/BannerlordCoopLauncher-v1.6.8-win-x64.zip)

下载后“全部解压”，双击“骑砍2开服助手.exe”。成品包仅包含程序和使用说明。

服务器控制台默认在后台运行，不添加独立任务栏图标。需要时在助手内查看日志，或手动显示独立窗口；独立窗口也不添加任务栏入口。助手主窗口保留任务栏图标。

保留默认“开服与存档”页和关闭助手时保存并停止服务器的功能。

运行条件：64 位 Windows 与 .NET Framework 4.8；开服还需 Steam、游戏、Bannerlord Co-op 和完整 DedicatedServer。已适配 Coop 0.1.6 / 游戏 1.4.8。

发布前在 Windows 上校验源文件、编译并运行内置检查。真实 MOD 服务器环境仍需本机确认。
