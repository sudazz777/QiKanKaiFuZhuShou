# 骑砍2开服助手 v1.6.5

[⬇ 下载 Windows 64 位成品](https://github.com/sudazz777/QiKanKaiFuZhuShou/releases/download/v1.6.5/BannerlordCoopLauncher-v1.6.5-win-x64.zip)

下载后“全部解压”，双击“骑砍2开服助手.exe”。成品包仅包含程序和使用说明。

- 启动服务器时默认隐藏独立黑色控制台，日志和交互提示整合到助手的“服务器控制台”页。
- 显示最近 120 行原生控制台输出，支持暂停刷新、输入命令及按需显示独立窗口。
- 保留原服务器输入通道，保存、重启与停止仍使用现有流程。
- 关闭助手时恢复服务器独立控制台，继续运行服务器。
- 保留 v1.6.4 的新电脑兼容修复。

运行条件：64 位 Windows 与 .NET Framework 4.8；开服还需 Steam、游戏、Bannerlord Co-op 和完整 DedicatedServer。已适配 Coop 0.1.6 / 游戏 1.4.8。

发布前在 Windows 上校验源文件、编译并运行内置自检。控制台验证使用独立模拟进程，不启动游戏服务器、不修改真实存档。真实服务器及好友 Steam 加入仍需在实际环境中验证。
